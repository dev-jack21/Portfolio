# Jackson Omondi Mula | Portfolio

Static portfolio site. No build step: just `index.html` and `assets/`.

## Before you publish
1. Replace `your.email@example.com` in `index.html` with your real email.
2. Replace the LinkedIn URL in the Contact section.
3. Add GitHub links to your projects (copy the `<a class="link">` line from the Project-Mgt entry).

## Publish on GitHub Pages
1. Create a repo named `dev-jack21.github.io` (or any name, e.g. `portfolio`).
2. Upload `index.html`, `assets/` and this README to the repo root.
3. Go to Settings > Pages, set Source to "Deploy from a branch", choose `main` and `/ (root)`, then save.
4. Your site goes live at `https://dev-jack21.github.io/` (or `/portfolio/` for a differently named repo).
